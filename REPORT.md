# Отчет по практической работе №7

## Тема

Реализация паттерна Prototype на языке C#.

## Вариант

Вариант 1 - журнал документов.

По заданию нужно определить базовый класс `Document`, созданный по принципу Prototype, а также создать подклассы разных типов документов: `TxtDocument`, `DocDocument`, `PdfDocument`. Программа должна создавать несколько документов и клонировать их.

## Цель работы

Изучить паттерн Prototype и реализовать программу, где новые объекты создаются копированием уже существующих объектов.

## Краткая теория

Prototype, или "Прототип", - это порождающий паттерн проектирования. Его смысл в том, что новый объект создается не напрямую через конструктор с нуля, а через копирование уже готового объекта.

Это удобно, когда объект уже содержит нужные данные и нужно быстро получить похожий экземпляр.

## Ход решения задачи

### 1. Создание базового класса Document

Был создан абстрактный класс `Document`. Он содержит общие поля для всех документов:

- `Title` - название документа;
- `Author` - автор;
- `Pages` - количество страниц.

Также в нем объявлен абстрактный метод `Clone()`. Он нужен, чтобы каждый конкретный документ мог создать свою копию.

### 2. Создание TxtDocument

Класс `TxtDocument` наследуется от `Document` и описывает TXT-документ.

Дополнительное поле:

- `Encoding` - кодировка файла.

Метод `Clone()` создает копию TXT-документа через `MemberwiseClone()`.

### 3. Создание DocDocument

Класс `DocDocument` описывает DOC-документ.

Дополнительное поле:

- `HasFormatting` - есть ли форматирование.

Метод `Clone()` также использует `MemberwiseClone()`.

### 4. Создание PdfDocument

Класс `PdfDocument` описывает PDF-документ.

Дополнительное поле:

- `IsProtected` - защищен ли документ.

Метод `Clone()` создает копию PDF-документа.

### 5. Использование объектов в программе

В основной части программы создаются три оригинальных документа:

```csharp
Document txt = new TxtDocument("Заметки", "Иван", 3, "UTF-8");
Document doc = new DocDocument("Отчет", "Мария", 12, true);
Document pdf = new PdfDocument("Инструкция", "Петр", 20, false);
```

Затем каждый документ клонируется:

```csharp
Document txtCopy = txt.Clone();
Document docCopy = doc.Clone();
Document pdfCopy = pdf.Clone();
```

У копий изменяется название, чтобы показать, что это отдельные объекты.

Программа выводит оригинальные документы и их копии:

```text
Оригинал: PDF: Инструкция, автор: Петр, страниц: 20, не защищен
Клон:     PDF: Инструкция - копия, автор: Петр, страниц: 20, не защищен
```

## Ответы на контрольные вопросы

### 1. В чем суть паттерна Prototype?

Суть Prototype в том, что новые объекты создаются путем клонирования существующих объектов-прототипов.

### 2. Опишите базовую реализацию паттерна Prototype на C#

Базовая реализация включает абстрактный класс или интерфейс с методом `Clone()` и конкретные классы, которые реализуют этот метод. В C# для простого копирования можно использовать `MemberwiseClone()`.

### 3. Перечислите преимущества и недостатки паттерна Prototype

Преимущества:

- удобно создавать похожие объекты;
- не нужно каждый раз заполнять объект с нуля;
- уменьшается зависимость от конкретных конструкторов;
- можно быстро получить копию готового объекта.

Недостатки:

- при сложных объектах может понадобиться глубокое копирование;
- `MemberwiseClone()` делает поверхностную копию;
- при изменении структуры классов нужно следить за правильностью клонирования.
